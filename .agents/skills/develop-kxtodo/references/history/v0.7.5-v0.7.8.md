（下面四块原本是 AGENTS.md 里「记账」长段落之后的四个独立段落，**文字一字未改**，只从列表项提升为小节。）

### v0.7.5 界面与数据打磨

① **列表汇总灰字**：月份条与日卡标题行的收/支/结余统一 #93989f（与周几同色），红绿只留给每笔金额——汇总行五颜六色抢正文语义。② **无备注条目 solo 布局**：分类名跟图标一样上下居中、右侧金额与时刻/账户仍叠两行（`.ledger-entry-main.solo`）；有备注保持两行卡片。③ **条目多图**：`LedgerEntry.image` → `images: string[]`（core add/modify/transfer 收 `images` 数组、modify 给了就整体替换、CLI `--image` 可重复、GC 与存储盘点按并集）；**v0.7.4 的单数 `image` 字段在加载 normalize 时一次性折叠进 images**（core `fold_legacy_image` + 前端 `normalizeLedgerEntry` 两侧都做——用户真实账本里的图不能丢，这是「不做兼容」铁律的唯一例外，重写后旧键不再落盘）。编辑器：无图点相机多选（桌面原生对话框 `pickImageFiles` multiple / 移动 file input multiple），有图按钮点亮 + 右下角数量角标，点它进全屏预览管理——预览右上角 X/+/垃圾桶三个同风格圆钮、多图左右翻页（键盘 ←→ 同）、删除只改草稿；卡片小字行的图片图标同样带张数角标。**桌面预览「展示不全」的根因**：img 是 grid 子项，百分比 max-width 压不住 grid 的「自动最小尺寸」（= 内容尺寸），必须显式 `min-width/min-height: 0`。顺手修了 LedgerImagePreview 的 Esc 守卫写反（`keyCode !== 229` 导致 Esc 永远关不掉）。④ **编辑器分类网格列数写死**（桌面 7 / 移动 5，CSS repeat 与组件里算「行尾」的 cols 必须一致，auto-fill 的不确定列数算不出行尾）：二级阴影区是**插在「大类所在行的行尾格子」之后的整宽 grid 子项**（`grid-column: 1/-1`，auto-placement 自动把它放到紧接着的下一行——「在它所在行下面展开」的字面实现；早前挂在整张网格末尾）；展开时 `scrollIntoView({block:"nearest"})` 把搁板带进视野。桌面对话框宽高各增一个图标尺寸（560→626、max-height 780→846、分类区 340→406）；**移动端抽屉定高 `min(92vh, 780px)` 恰好露出五排图标**（分类区 `flex:1` + `max-height:none`——旧的 340px 上限会压住五排；图标多了滚动、少了不缩矮），转账仍 `height:auto`。⑤ **统计段控分平台**：桌面「周/月/年/总/自定义 + 支出/收入/结余」，移动去「周」+ 短文案「月/年/总/自定义 + 支/收/结余」+ padding/字号收紧（超屏的段控会把下面的日期弹层一起带出界）。侧第三项从「收支」改「**结余**」：画三条曲线（支出红/收入绿/结余=收-支 黑 `.ledger-line.bal`），纵轴按有符号区间自适应（lo<0 画虚线零线）。**修「NaN月」**：桶类型判定写反（day 键长 10 被 `>7` 判成 month 桶，`Number("09-14")`=NaN）——正确判据 `key.length === 7 ? month : day`。**趋势读数**：桌面悬浮/移动点按最近的桶，标记线 + 各曲线圆点 + 顶部浮签（`.ledger-chart-tip`）；换周期/侧/区间由 `{#key}` 重画并清读数。⑥ **移动端浮层超屏的真凶（波及任务/日记/记账所有页）**：四个主滚动区（`.task-list`/`.scheduled-list`/`.diary-scroll`/`.ledger-scroll`）的 `margin-right:-56px + padding-right:51px` 是给**桌面滚动条**留位的技巧——移动端覆盖式滚动条下负边距把滚动区整个往右顶出屏幕（实测 scrollWidth 562 vs clientWidth 520），按它算宽度/锚定的浮层全跟着出界；mobile.css 一律清零。统计自定义起止的 DatePicker 浮层另加 `clampPopoverToViewport` 兜底。⑦ **半屏抽屉滚不到底**：表单里图标网格（`overflow-y:auto; max-height:178px`）是第二层滚动区，触屏手势被它吃掉、外层表单永远差最后几行（「添加账户看不到底部的账户名预览」）——**移动端 `.ledger-sheet-body .ledger-icon-grid` 完全展开**（半屏抽屉里只许一层滚动），桌面保留内滚（鼠标滚轮无此问题）。⑧ **桌面日卡右上角 + 常驻**（旧 opacity:0 hover 才显——不 hover 时卡片缺一角），hover 提亮保留。⑨ **占比环出场动效**：整环 rotate(-140°)+scale(0.78) 归位（0.85s）+ 每片按 `--i` 错帧从 0 描边展开（keyframes 只写 from 帧、to 即属性上的最终弧长、backwards 填充）+ 引线/环心文字延迟淡入；首次挂载跑一次、数据变化不重放（keyed 元素复用）。**点选环心的测试必须等动画完再量坐标**（动画中 bbox 是变换中的位置）。⑩ **自定义账户类型成为账本级持久实体**：`LedgerFile.accountTypes`（`{id:"latype-…",name,icon,color,createdAt,updatedAt}`，账户的 kind 字符串 = 类型名）、第四种同步实体 kind `ledgerAccountType`（merge/engine 按 ledgerAccount 的模式全套：LWW + 墓碑 + 全新设备清档），core 命令 `ledger.accountTypeAdd/Modify/Remove` + 只读 `ledger.accountTypes`，CLI kebab `account-type-*`（三个写命令进确认门与 high-risk-write）；名字唯一（`LEDGER_ACCOUNT_TYPE_EXISTS`）；删类型不影响已建账户（kind 字符串与账户自带图标颜色还在）。UI：类型 chips = 预置 + 自定义（带自己的图标与颜色、chip 上铅笔进编辑、表单里可删），加号开行内小表单（名称 + 账户图标目录 + 颜色），建好即选中。**编辑账户 = 直设「当前金额」**：表单预填推导余额（`accountBalance`），保存发 `balance`（与 `initial` 互斥，同发报 `LEDGER_PARAM_CONFLICT`），core 用 `ledger balance` 同源的推导把差额折回期初（期初 = 目标余额 − 流水净额）——**余额始终只有「期初 + 流水」一个数据源**；`parseYuanToCents` 放开负数（信用卡）。**顺带修了 v0.7.0 就在的真 bug**：core `cents_param` 把 JSON 整数按「分」、小数按「元」解释，而 GUI 发 `initialCents/100`——整数元（最常见）被当成分、期初缩小 100 倍；GUI 一律改发整数分（与 amountCents 同口径）。⑪ **总资产趋势图**（`AssetsTrend.svelte` 纯 SVG + `AssetsTrendViewer.svelte`）：`ledger.ts::assetsTrend(book)` 从最早一天（首笔流水或账户创建日）扫到今天，采样步长按跨度自适应（≤90 点、首尾必落、起点前一格给「只有期初」的水平段），口径与 `assetsOverview` 完全一致（净资产 + 信用类负余额负债）；纵轴 1/2/5×10ⁿ 取整刻度、横轴 ≤4 档稀疏刻度 + 格式随跨度（>400 天 YYYY/M、跨年 YY/M/D、同年 M/D），少标签无注释。桌面 = 净资产卡右侧并排（5fr/7fr），点击浮窗放大 + 悬浮读数；移动 = 纵排夹在净资产与资金账户之间，点击**横屏全屏**（整层 rotate(90°)、宽高对调，组件量遮罩视觉 rect ÷ uiScale 给布局尺寸）。**viewer 必须挂 LedgerView 顶层**：挂在 `.ledger-scroll` 里会被它 z-index:1 的 stacking context 困住——z-index 4600 的全屏层被 z-40 的 FAB 盖住（实测抓到的）。

### v0.7.6 界面与数据打磨

### v0.7.8 输入法跟随与超链接卡片打磨

① **移动端点「添加事项」不再把整页顶上去**（`src/lib/imeViewport.ts`）：安卓 WebView 在 edge-to-edge 下键盘弹起时并不缩布局视口（`100vh` 不变），聚焦的输入框落在键盘底下，浏览器只能把**视觉视口**往上顶（`visualViewport.offsetTop`）——表现就是「一点输入框整个页面被顶上去、条目位置跟着变」。现在 app-shell 自己收矮到「键盘之上的可见区域」（高度 = 视觉视口高 ÷ uiScale）并跟随那次平移（`translateY(offsetTop)`，父容器没缩放所以是布局像素；内联 transform 必须把 `scale()` 一起写回来），页面就没有可顶的东西了：条目原地不动、输入框正好在键盘上沿。只在**捏合缩放为 1**（`vv.scale ≤ 1.01`）且收缩超过 80px
