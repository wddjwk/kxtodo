# v0.4 版本档案（v0.4.0 – v0.4.1）

> **这份文件是什么**：v0.4.x 的**改动索引**——这一版做了什么、全文现在搬去了哪个主题文件的哪一节。不是当前架构描述。
> **什么时候读它**：要追溯「同步第一次落地时是怎么设计的」「自动同步第一版为什么是死代码」「server 运维参数从哪来」。
> 用法与这个目录的定位见 `README.md`。

## 这一版的主题

v0.4.0 是**数据多端同步首次落地**（`crates/server` + core `sync` 模块：XChaCha20-Poly1305 密文、逐实体 LWW + 墓碑、OCC 版本号、SQLite 只存密文）；v0.4.1 补的是 **server 运维**（启动参数持久化、日志按日轮转、管理界面、token 有效期）与**自动同步第一版**（`sync.intervalSeconds` + `syncRunner.ts`——这一版后来被查明是死代码，v0.5.0 重写）。
