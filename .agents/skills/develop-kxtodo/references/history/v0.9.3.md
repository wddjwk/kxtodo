## 逐条流水账

### ① 通知窗焦点

链路：scheduler 500ms → reminders.poll → host.show_notification_payload → TauriBackend::show_notification → 非 Linux 建自绘窗（notification.html）。旧 builder 无 focused 参数、两处 `window.show()`（notification_ready 与 900ms 兜底）在 Windows 都激活窗口。修：builder `.focused(false)` + 建窗后 `notification_no_activate`（GetWindowLongPtrW/SetWindowLongPtrW 挂 WS_EX_NOACTIVATE，SetWindowPos SWP_FRAMECHANGED|SWP_NOACTIVATE 生效）。WS_EX_NOACTIVATE 下 show 与点击都不激活、鼠标消息照送 → 窗内关闭按钮仍可用。hwnd 类型坑：tauri 返回 windows crate 的 HWND 新类型，`raw as windows_sys::HWND` 报 E0605，取 `raw.0`。

### ② AppImage 基底

报错六条全指向 AppImage 内打包库（libglib/libwebkit2gtk/libjavascriptcoregtk/liblcms2/libjxl）要求 GLIBC_2.42/2.43。查证：workflows 自 v0.8.0 一笔未改 → 只能是 runner 镜像漂移；打包链零 linuxdeploy 定制。pin ubuntu-22.04（glibc 2.35，webkit2gtk-4.1-dev 在 jammy 有）。ci.yml rust-linux 同 pin（编译检查也要在发布基底上过，且 rust-cache shared-key 一致）。release.sh 用 getconf GNU_LIBC_VERSION 告警本地高基底构建。**未验证**：22.04 runner 上的实际构建交 CI（本機 Windows 无法跑 Linux 打包）。

### ③ 今天高亮圆

v0.9.2 已修 align/flex/桌面直径，移动端覆盖只把圆缩到 font+2 而字号仍 font-1：两位 tabular 粗体宽 ≈1.2em > 圆在字高半处弦宽 → 白字四角出圆、落在 rgb(255 255 255 / 82%) 头底上＝「显示不全」（不是 overflow 裁切）。修：圆 font+6、字号 font-4；弦宽余量验算 F=18/D=28 时 25≥21.6 ✓。回归用 Range.selectNodeContents 量文字真实 rect（只数事件/看最终值测不出这种观感 bug）。

### ④ 时间行与括号

移动端旧文案「今天 · 11月19日 周三 · 09:00」在 360px（scale=1 时值列 ≈194px）必截尾。紧凑档：相对日 = `今天 11/19`（不带星期）、非相对 = `11/19 周三`、跨年 = `2027/11/19`；桌面一字未改。括号旧实现是「右列一个按钮块 + 单行省略」，用户点名丑且不换行。新：桌面 = 透明底 flex，`.cal-duration-bracket-line`（7px 宽、右竖线+上下臂、border-left:0）跨两行 stretch，文字 align-self:center 可换行；hover/全天态只改颜色不改底。移动端 = grid 单列，括号 grid-column 1/-1 下移成块：横括号（上边+两臂）罩居中文字、淡底圆角。时长菜单（15min…3h/全天）与 normalizeMidnightEnd 语义一字未动。

### ⑤ 分类面板

对照 Outlook「管理分类」/ Todoist 标签管理器：列表行色点+名称+星+删除、整行进编辑；底部全宽添加按钮；表单色板选中打勾（Check 白图标）、自定义走 openColorPicker 单例（key `calendar:category-color` 不变）、默认星形开关、迷你事件块预览保留但解释长句删。空态只留「还没有分类」。删除 toast 缩短为「分类「X」已删除」。返回键层级不变（先退表单再关面板；startWithAdd 直达表单退=关）。

### ⑥ 习惯打卡

设计对照时光序截图：全部视图 = 进行中/已暂停/已完成三计数页签（下划线指示）+ 卡片（图标圆 soft 底 + 名称 + 频率·时刻 + 右侧 N天/累计打卡）；每日视图 = 日期导航 + —全天/上午/下午/晚上— 分组 + 三列图标圆阵（点圆=打卡，checked = soft 底 + 主色内环 + pop 动画）。点卡片进统计面板：四格（累计/当前连续/最长连续/本月）+ 近 30 天完成率条 + 月历热力图（打卡实心/计划内空心/今天描边，周起始跟 weekStart 偏好）。右键/长按菜单：打卡今天/编辑/统计/暂停/标记完成/恢复/删除（两步确认）。编辑器：名称/图标（懒加载 IconPicker icon 模式）/颜色（12 色板+自定义）/计划（每天+七个星期 checkable，选空自动回 daily）/时间（全天+预设+自定义 time input）/提醒（due 预设+自定义 date/time，芯片可删）。

统计口径：连续按**计划内相邻出现**算（weekly 的「连续」是相邻两次计划日，不是自然日相邻）——currentStreak 今天没打不算断、从上一个计划日往回；bestStreak 用 nextScheduled 切段。完成率 = 近 30 天计划内打卡占比。

同步：kind `habit` 整条 LWW（checkins 在载荷里，与任务 markdown 整段覆盖同取舍）；搭 data 范围，无新勾选。提醒：plan_habits 只规划 active、视野 45 天+提前量（封顶 366 防脏数据撑爆循环）、收据键含 at 各日一条；重检验 status/scheduled_on/规则同瞬时。

踩坑两枚：HabitTool 的 `$: statsHabit = f(statsId)` + `$: if (statsId && !statsHabit) statsId = null` 成响应式环（Svelte 编译报 reactive_declaration_cycle）→ 判据改直接读 list；HabitEditor 的 ContextMenu 挂 overlay 外被遮罩盖住（3.23 第四条）。

### ⑦ 剪切板发送端无感

检查结论：发送端只读不写（poller 仅在服务启用时跑；基线/序列号/last_remote 三道闸防回声），但 read() 里 repair_zero_alpha 会改发送像素＝「对内容做处理」。移修复到接收端单一入口 repair_png_alpha，且必须在 apply_remote 记水位前（水位=修复后指纹，写回读回才匹配；否则 Linux 无序列号会把修复版当新复制回声给发送端、覆盖发送方剪切板——比原 bug 更糟）。正常图（有非 0 alpha）原字节返回不重编码＝零损失。桌面 write 的两处 repair 删（接收端已修，冗余）。另治 Linux 纯图剪切板每 800ms 重编码 PNG：encode_image_cached 指纹缓存。**未验证**：两机真机互发（含全 0 alpha 截图工具源）、安卓桥写回修复版 PNG 的观感——交真机手测。
