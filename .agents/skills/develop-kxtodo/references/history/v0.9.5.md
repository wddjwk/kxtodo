# v0.9.5 改动索引

主题：**标语栏重做**（六位置 / 边界可配 / 条目卡片化 + 每项图标含 emoji / 跑马灯 / 主题色与字色与透明度 /
轮播间隔且去进度条 / 任务右键一键设为标语）。其余为沿用 v0.9.4 的修补。

## 一、六位置 + 边界基准（需求 1、8）

- 位置从 top/bottom 两档扩成 **六档**：`top-left / top-center / top-right / bottom-left / bottom-center / bottom-right`
  （`Slogan.position`，core `SLOGAN_POSITIONS` 校验）。顶部 = 贴内容区（.list-header）上缘再上一条；底部 =
  贴内容区底部（不再锚定输入框——没有输入框的页面此前会卡在顶部）。**有浮动加号时抬到加号上方**避开遮挡
  （`.diary-fab-row / .ledger-fab-row / .calendar-fab-row / .scheduler-floating-add`）。
- 新增 `Slogan.bounds`（`field` 默认 / `app`）：左右边界基准。`field` = 输入框 → 任务列表 → 页头（跟卡片区对齐）；
  `app` = 可见页根容器（程序右半区边界）。工具页二选一段控。
- 横幅改为 `.slogan-layer`（fixed、层 `pointer-events:none`、胶囊 `auto`）+ 胶囊 pos-left/center/right 的
  margin 对齐；坐标仍布局像素（rect 差 ÷ uiScale）。

## 二、条目卡片化 + 每项图标（需求 2、11、12）

- `SloganItem` 增加 `icon`（空=默认喇叭 / "none" / lucide 白名单名 / **emoji**）；全局 `Slogan.icon` 删除。
- core 新增 `is_slogan_icon_value` / `is_slogan_emoji`（非 ASCII、无空白、≤12 码点——与前端
  `isSloganEmoji` 同口径）；`gui.set-slogan` 条目图标与 `defaultIcon` 都走它。
- 新增 `Slogan.defaultIcon`（新标语默认图标，工具页可配；含 emoji）+ `Slogan.bounds`。
- 工具页列表改成卡片：勾选（展示）+ 图标按钮（默认喇叭/不加/选择图标/选择 Emoji）+ 点文字直接行内编辑
  （保存按钮 + Enter 保存 / Esc 取消，不再靠铅笔按钮与失焦）+ 两步删除。新增「新标语默认图标」行。
- `SloganIcon.svelte` 统一渲染三态（lucide 组件 / emoji 字形 / 不渲染），banner/卡片/预览共用。

## 三、无叉号 + 悬浮全文（需求 9、10）

- 胶囊上**删除 X 关闭按钮**：点胶囊本体 = 进标语栏工具页，用户自己去关开关（enabled 保留在工具页）。
- `title` 只在**超 30 字需要滚动**时才挂（短标语悬浮不再弹全文）。
- 超 30 字宽：`.slogan-banner-text.marquee` 横向来回滚动（rAF 测 `scrollWidth - clientWidth` 得位移与时长，
  CSS keyframes `slogan-marquee`）；显示宽度上限 30em。

## 四、颜色与轮播（需求 6、7）

- 新增 `accent`（主题色：图标与描边）/ `textColor`（字体颜色）/ `opacity`（背景透明度 0.3–1，默认 0.94）/
  `intervalSeconds`（轮播间隔 2–120 秒，默认 8）。
- **去掉轮播进度条**：定时器按 `intervalSeconds` 换帧；悬停暂停；`rotationKey` 把「名单长度:间隔毫秒」当
  字面依赖，名单或间隔变化时重建定时器。
- 工具页取色走全应用唯一 `openColorPicker` 单例；**onPreview 只改本地草稿（colorDraft），确认才落盘**
  （拖动过程不能写 core）。

## 五、任务右键「设置为标语」（需求 11）

- `taskMenuConfig.ts` 注册表新增 `saveSlogan`（默认可见，排在「添加表情」之后）；管理面板/数量断言随之
  15 项（v092 的 7.3 与 taskMenuConfig.spec 同步更新）。
- Workspace 分支：取任务 markdown 第一行（`sloganTextFromMarkdown` 去 #/>/列表/勾选/强调符，截 80），
  **用 `defaultIcon`** 生成条目，追加并自动选中；重复内容 toast「已经在标语里」，上限 50 条。

## 六、本版踩坑

- **MenuItem 的 onSelect 在菜单关闭之后执行**：handler 里读「菜单 state」（如 `iconMenu?.itemId`）时它已被
  `onClose` 清空 → 点了没反应。做法：打开菜单时把 id 另存一份（`iconMenuItemId`），onSelect 用那份。
- **复用类名会坑测试选择器**：默认图标触发器内层一开始也用了 `.slogan-item-icon`，v095 3.8 的
  `.slogan-item-icon.first()` 点到默认触发器，表现成「条目图标改不动」的假象。改类名语义化
  （`.slogan-default-icon`）后一次通过。
- **computed style 的 `max-width` 是 `min(100%, 483px)` 字符串**：`parseFloat` 得 NaN，断言要用正则取 px。
- DataFile 未加字段，merge 的 `empty_data()` 无需动；但 Slogan 结构体加字段仍要更新 core 测试与
  merge extract/apply（extract 显式列字段，漏了远端同步丢配置）。
