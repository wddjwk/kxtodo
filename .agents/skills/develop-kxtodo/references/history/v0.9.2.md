## 逐版流水账

### 一、skip_ahead：低估方向才安全

探针实证：2023-01-15 开始的「每月 15 日」，查 2026-11 视图返回空——创建约 3.5 年后的
月度日程从所有视图消失，`plan_calendar` 用同一函数，提醒一并静默停发。根因：每步天数按
28/365 估（28 是一个月的**最小**天数），估出的步数超前，回退 2 步的余量只够 ~2 年。
修法一行两边同改：月 31、年 366。用例表两边各补「start 距 from 超 2 年」一条
（`monthly_skip_ahead_does_not_overshoot_far_ranges` / 「每月：start 距查询区间超过 2 年仍展得出来」）。

### 二、重复日程提醒：规划与重检同口径

规划按当次出现日解析 `BeforeDue`，发前重检却用 `resolve(rule, Some(event.start_date))`——
系列开始日。除第一次外必然匹配不上 → `current = None` → 记 cancelled → 台账永久封死。
`PlannedReminder` 加 `occurrence_date`（任务提醒为 None），重检改用它，并且**再验该日仍是
系列的一次出现**（系列被拖动/改规则后该日作废 → 取消）。集成测试钉「每次出现各一条、
出现日升序、收据键互不相同」。

### 三、24:00 结束：全链路一种表示法

core 约定 = `endDate` 次日 + `endTime` "00:00"。三处互斥表示法收口：
`segmentForDay` 的 `endMin === 0` 改「该天不覆盖」返回 null（旧代码折 1440 → 次日幽灵全天块 +
月视图多一枚芯片）；`eventCoversDay` 走新的 `lastCoveredDate`（午夜结束的最后覆盖日 = endDate−1）；
拖拽 onUp 写「次日 + 00:00」（旧代码写「当天 + 00:00」→ core 拒倒挂，拖到网格底部保存必失败）；
`absRange` 对「次日 + 00:00」的绝对结束分钟就是次日零点整——旧的 `endMinutes || 1440` 会把
它折成再下一天，**每拖一次系列长一天**。编辑器结束时刻选到 00:00 也自动进位（`normalizeMidnightEnd`）。
`calendar.spec.ts` 旧契约钉的是 core 根本不会产出的表示法，改写成两条新契约。

### 四、现在红线：第四踩藏依赖

`style={nowLineStyle()}` 把 `nowMinutes`/`totalHeight` 藏进函数体，编译产物 untrack、只算一次。
改 `$: nowLineStyle = …`（依赖字面出现），totalHeight 进依赖后 hourZoom 缩放红线跟着缩放
（v092 回归 3.2 钉「放大后 top 变大」）。同版又抓出一处无参写法：`$: rangeError = validateRange()`
永停初值 → 校验错误不显示、Esc 照关丢草稿（需求 6 的半个根因），改传五个实参。

### 五、移动端横滑方向

`onPrev: () => step(1)` 与 DiaryView/工具栏箭头/业界全部相反，对调。

### 六、Esc = 保存并关闭，保存不了就不能关

`persist()` 校验失败只 toast 不抛错、`saveAndClose` 无条件 `closed = true`——填了半天、结束时间
倒挂、按 Esc 内容直接没了。`persist` 改返回布尔，`saveAndClose` 失败保持打开（错误行已在表单里）。
全空新建的 implicit 放弃语义保留。

### 七、管理菜单项 + 三个截止快捷项

任务右键菜单改数据驱动：注册表 `taskMenuConfig.ts`（唯一白名单：11 个可见项 + 分隔线 `sep`
一等公民 + 三个 `defaultHidden` 的截止快捷项）；顺序与隐藏住 `appearance.taskMenu`
（`{order, hidden}`，本机偏好不进同步共享子集）。core 只校验形状（`expect_task_menu`），
**六处登记点**：core 四处 + `normalizeSettings` appearance 白名单 + `types.ts`。
管理面板 `TaskMenuManager.svelte`：pointer 拖手柄实时换位 + 眼睛显隐，改动即落盘，
footer 有「恢复默认」。菜单底部恒有「管理菜单项」入口。

### 八、分类与固定面板：照业界重做「原始」交互

分类表单的裸 checkbox 换星形开关（`.calendar-default-toggle`，星形是业界对「默认」的通用符号）；
侧栏「添加固定」的打勾列表换图钉填充行（`.nav-fixed-row`，整行可点、状态一眼可读），
面板限高自滚 + 取消/确认 sticky 在底（修「显示得不完全」）。
**取色盘 z-index 3600 → 4700**：它常从 editor-overlay(4000)/记账管理器(4200/4600) 里打开，
3600 时被整层盖住（「点自定义颜色色盘在添加分类界面底下」）。

### 九、移动端日程拖动：拖动就是拖动

旧路径要长按再点、长按还选中文本。新路径：触屏 pointerdown 越过 8px slop 即进拖动预览
（整体挪 / 上下边缘改时长同桌面），不 preventDefault pointerdown（保住 tap 的 click 开编辑），
`.cal-event` 移动端 `touch-action:none`（不交给浏览器滚动，否则 pointercancel 断手势）+
全局 `user-select:none`（长按不许选字）；改时长手柄移动端不隐藏，加高 14px + 淡 grip。
tap（未越 slop）照旧开编辑器。

### 十、编辑器时间行：去重复 + 时长括号

`dayLabel` 旧实现把 `relativeDayLabel`（同年份回落 fullDayLabel）与 `fullDayLabel` 拼在一起 →
「11月4日 周三 · 11月4日 周三 · 00:00」。新实现日期部分只出现一次（今天/明天/后天/昨天 前缀 +
跨年加年份）。全天勾选行删除：开始/结束两行右侧一个跨两行的**时长括号**（`.cal-duration-bracket`，
auto 列宽 + 文本省略，360px 也不顶出右边界），点开出 15min/30min/45min/1h/2h/3h/全天 快捷档，
截止一律由开始时间推算（跨午夜进位走 core 约定）；全天是括号里的一档。

### 十一、日期弹窗透明被挡：叠层上下文陷阱

v0.9.0 给 `.task-card` 加 `z-index:1`（压滑动露出层）后卡片自带 stacking context，卡内
fixed 的 `.task-date-popover`(2200) 被关进去，后面兄弟卡片（84% 半透明底）整块盖上来——
透过去看就是「弹窗是透明的还被条目挡」。修法：开弹窗时整行抬（`.task-swipe.date-pop-open`）。

### 十二、拖选自动滚动：选区是手势的敌人

拖选建日程时浏览器起文本选区，「选区 + 按住鼠标」触发滚动容器边缘自动滚动——网格中途自己
滚走、落点偏一格（v090 回归 2.1/2.4 实测 10:00–12:15 / 2.25 小时）。`.cal-grid` 一律
`user-select:none`。

### 十三、其余

事件块有地址时画 `.cal-event-loc`（单行省略，`.short` 块不画）；移动端「现在」改圆形定位图标
按钮右对齐（LocateFixed，文字标签移动端隐藏）；`durationText` 无消费者删除。
