## 这一版的主题（按小版本）

- **v0.7.0**：**记账域引入**（第五个领域文件 `ledger.json`：`accounts` / `categories` 两级 / `entries` 流水；金额一律整数分；余额 = 期初 + 流水推导；转账不计入收支统计；四个视图 list/calendar/stats/assets；确定性种子 id）。同步内容从三勾选框变**五勾选框**（日记与账本各一个，`Scopes` 五个 bool、scopeSignature 五段）。
- **v0.7.1**：记账**卡片化重写**（组织单位改成「天」，一天一张 `LedgerDayCard`；月份行；日历/统计/资产铺满内容宽）；`DatePicker`；踩了三个坑（齿轮下拉面板的包含块、`bind` 到 `{@const}` 指向的对象属性、浮层输入框 `stopPropagation` 吃掉 Escape）；Excel 归档（`ledger_archive.rs`）。
- **v0.7.2**：记账只有显式点保存才落盘；CLI 改账本必须先过确认门（退出码 10）；设置抽屉每个大类改可折叠分区；标题与标题下小字的关系统一；一般卡片不统计角标；编辑/预览页签改滑块切换；移动端行名比桌面大一档；左上角返回箭头删除；图片 GC 引入；一般卡片的 Markdown 压缩包收紧图片（图只跟引用走）+ 文件夹导入；移动端左上角返回箭头以特性开关回来（v0.7.6）。
- **v0.7.3**：时刻精确到分钟（`DatePicker` + `withTime` + `TimePicker` 滚轮）、保存语义钉死、改转账走 `ledger.modify`、统计钻取、图标目录扩到 20 组 228 个、记账字号独立、年月标签可点（`MonthPicker`）、转账浮层不被裁、汇总卡金额不许出省略号（`fitAmount`）；图片 GC 去掉宽限窗；「释放空间」（`ops_storage.rs`）；幽灵点击与浮层层级（`ghostClick.ts`）；设置分区重组与固定分组；同步账户不预填显示名。
- **v0.7.4**：条目两行卡片、列表单月换月（贴边整屏换月）、月份条对齐分平台、日历视图选中日贴当天卡片、统计重构（周期段控 + 侧段控 + 白底圆角卡 + 周/自定义）、钻取环独立配色、条目插图（伪条目 id = `ledger`）、编辑器重构（圆形分类网格 + 内联二级搁板 + 无框备注）、账户类型放开为自由字符串、两个管理器不 autofocus；设置抽屉存储空间列出占用组成。

## 逐版流水账全文

（下面两块原本嵌在 AGENTS.md 那个 6204 字符的「记账」长段落里，现按原切分点拆出，**文字一字未改**。`ledger.md` 保留了同一段落的前半部分：记账主描述、金额一律整数分、账户余额不存现值、组织单位是「天」、所有浮层复用 `.editor-overlay`、v0.7.2 起只有显式点保存才落盘。）

### v0.7.3 打磨

① **时刻精确到分钟**——`DatePicker` 加 `withTime`：日历与「清除/今天」之间一行「时钟 + 18:19」，点它把日网格**换成**双列滚轮（`TimePicker.svelte`，CSS scroll-snap 停位、停下来按 scrollTop/行高反推选中项；**换面板而不是往下追加**，否则锚在底部的记账浮层会被滚轮顶出屏幕）；账目的 `time` 是裸 `HH:MM[:SS]` 字段，显示用 `clock.ts::displayClock` 归一——**别拿 `clockOf`**（它按 ISO 时间戳从第 11 位切，喂裸时刻一律空串，v0.7.3 第一版记账卡片不显示时刻就是它）；任务的时刻是 `Item.dueTime`（随 item 整体进同步 payload，core 的 `time.rs::parse_clock` 归一），日记没有独立字段——时刻住在 `createdAt` 的时钟部分（导出 front-matter 同源，`diary.add/modify --time` 改的就是它）。② **统计钻取**（`ledger/CategoryDrilldown.svelte` + 抽出来的 `LedgerDonut.svelte`）：点排行的大类 → 移动端下半屏抽屉 / 桌面端锚在那一行下方的下拉面板（`anchoredPopoverStyle`，`popover.ts`），里面是该大类的二级分类占比环 + 明细行，点二级分类看账单明细，点明细直接进编辑器改；占比环因此抽成组件给统计视图与钻取面板共用。③ **图标目录**：前端 `ledgerIcons.ts` 扩到 20 组 228 个（`LEDGER_ICON_GROUPS`，分类管理的图标网格先按组筛），core 侧 `ledger_icons.rs` 是它的镜像（一次性脚本生成），`ledger icon-list` 把目录吐给 Agent 设计分类；一致性由 `tests/ledger_icons.rs` 守着（include_str! 前端 TS 逐个比对 + 种子账本只用目录里的图标）。记账面板的大类 chips 行末与子分类网格末尾各有一个加号，直达分类管理的新增表单（`stores.ledgerCategoryDraft` 递话：面板挂 App 层、管理器在 LedgerView 上，两棵不相干的子树）。④ **记账字号独立**：`appearance.ledgerFontSize/diaryFontSize` → `--font-ledger/--font-diary`（ledger.css/diary.css 全量改吃这两个变量，不再跟 `--font-control`）；`UI 字号` 管分组分类与页面标题，`Markdown 字号` 改名「正文字号」。⑤ **年月标签可点**：记账列表月份行、记账/日记日历栏、统计周期、我的一天日历面板的「‹ 2026年9月 ›」都是触发器，点开来 `MonthPicker`（年步进 + 12 个月 / 12 个年两档），外壳 `MonthPopover.svelte` 负责 fixed 定位与点外面关。⑥ **转账账户浮层不再被裁**：转账那一块（`.ledger-transfer-block`）刻意不进 `.ledger-sheet-body` 滚动区（滚动容器会裁掉往上开的浮层，表现成「被金额行盖住」），浮层改朝下开。⑦ 汇总卡的金额**不许出省略号**：字号统一收一档 + `fitText.ts::fitAmount` 按内容一档档缩到放得下（`use:fitAmount={value}` 必须传值，无参 action 的 update 不会被调用）。

### v0.7.4 界面改写

① **条目两行卡片**——标题行 = 月/日 + 周几 + 右端当天收/支与加号；每笔图标跨两行，大字行 = 分类名左 + 带符号金额右，小字行 = 备注（有插图时跟一个图片图标）左 + 时刻/账户右；**所有展示条目的地方统一这套**（列表 / 日历选中日 / 钻取账单明细）。② **列表单月换月**：不再往下堆月份栈——滚到底整屏换成上一个月并更新月份条，滚到顶下拉换回较新月（上限当前真实月）；换完先收边缘武装（`edgeArmed`），等滚回中间再武装，否则停在顶/底时每个 scroll 事件都会再翻一个月。③ **月份条对齐**：桌面同一行月份左、收/支/结余右；移动端拆两行（月份左、合计右）。④ **日历视图**选中日下方直接贴当天卡片（日历 空行 卡片），日头行删除。⑤ **统计重构**：顶行左 = 周期段控（周/月/年/总/自定义）、右 = 侧段控（支出/收入/收支）；下面一整块白底圆角卡 = 可点周期标签（年 `2026`、月 `2026/09`、周 `2026/09/14-09/20`、总/自定义起止全写）+ 三标签行 + 三数额行；周 = 周一起算的锚点日（`weekStartOf`），自定义 = 起止两个 DatePicker；侧 = 收支时趋势把收/支两条线画在同一张图（`收支趋势`），分类占比仍按支出（环的语义是"钱花在哪"）；「xx 个日子」「点一类查看它的明细」两条小字删除；周期窗口统一成 `statsBounds` 的 `{from,to}`（`statsSeries` 按跨度自动逐天/逐月分桶）。⑥ **钻取环独立配色**：二级分类默认继承大类颜色，照抄的话整个环一块色——自己没填颜色的按序号取 `DONUT_PALETTE`，行图标/进度条与环同色。⑦ **条目插图**：走 markdown 插图同一条通道、伪条目 id = `ledger`（`LEDGER_IMAGE_NODE`，core 的 inventory 是动态 read_dir 所以自动进同步与盘点）；`LedgerEntry.image` 存裸文件名（core add/modify/transfer 都收，`--image` 同）；卡片小字行的图片图标与条目菜单「查看图片」都开 `LedgerImagePreview.svelte` 全屏罩（z-index 4600，盖住一切记账浮层）。⑧ **编辑器重构**：删掉「选择分类 金额」行——一级分类 = 圆图标 + 名字的网格，点有二级的大类在它**所在行下面**展开一块全宽阴影的二级区（不是悬浮菜单），没有二级的大类点一下即选中；「添加备注」是无框纯文字输入（点它唤起输入法），金额右对齐大字（移动端仍只由键盘驱动）；日期/账户/图片一行纯文字按钮不带底；**移动端抽屉高度恒定**（`height: min(78vh, 640px)`），分类区自己滚动且藏滚动条，图标多少都不撑高或缩矮。⑨ **账户类型放开为自由字符串**（core 校验只要求 trim 非空，负债判据 `kind == "credit"`）：预置表在 `ledgerAccountTypes.ts`（现金/银行卡/储蓄卡/信用卡/微信/支付宝/数字人民币/公积金/医保/公交卡/饭卡/押金/股票/基金/借入/借出/虚拟货币/投资/其他，各带默认图标与颜色），类型行末加号可自定义；账户图标走**独立目录** `LEDGER_ACCOUNT_ICON_GROUPS`（6 组 42 个，core `ledger_icons.rs` 镜像、`ledger icon-list` 返回 `accountGroups`），与分类图标目录互不混用；`defaults.ts` 的 normalize 对 kind 只兜底缺省、对 `image` 原样保留（漏了这两条，浏览器预览与核快照会把自定义类型压回 cash、把图片吃掉）。⑩ **两个管理器打开都不 autofocus 名称输入框**（一进去就拉输入法是打扰）。
