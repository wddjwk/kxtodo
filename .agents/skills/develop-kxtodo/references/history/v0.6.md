# v0.6 版本档案（v0.6.0 – v0.6.11）

> **这份文件是什么**：v0.6.x 的**改动索引**——这一版做了什么、全文现在搬去了哪个主题文件的哪一节。不是当前架构描述。
> **什么时候读它**：要追溯传输分层、内置主机、instance epoch、P2P、端口生命周期、日记域、markdown 扩展渲染、移动端手势与菜单、编辑器工具栏、特性开关、一般卡片压缩包的来历；或想知道某个方案「试过又被推翻」的经过。
> 用法与这个目录的定位见 `README.md`。

## 这一版的主题（按小版本）

- **v0.6.0**：传输分层（`transport` / `endpoint` / `engine` / `merge` / `crypto`，换通信方式只动 endpoint）、`sync.mode` = `lan|server|p2p`、**内置主机**（server crate 加 lib 目标，GUI/APK 进程内跑）、主机身份是名字（`sync.lanName` / `sync.lanPeer`）、`runtime/sync-host.json`、**instance epoch**（换主机/库重建自愈）、统一 `sync pair`、端口上移。
- **v0.6.1**：P2P 同步落地（iroh 1.1，账户派生密钥签的 pkarr 目录）。
- **v0.6.2**：P2P 补设备名、更新下载健壮化、设置面板同步卡片重排收口、端口释放（`ServerHandle::shutdown` 有界等待）、移动端展开/折叠/编辑全交给单击双击长按、任务卡片标签/表情/日期进正文流、内置链接预览标题栏、下拉同步、移动端 UX 一批修正。
- **v0.6.3**：P2P 改逐台对账、列表分区与排序（计划内互斥分区、已完成区固定降序）、折叠态标题省略号规则、托盘缺库降级、钻入式二级菜单仅移动端、菜单内输入不关菜单、同步节奏多端一致、手动同步重排周期。
- **v0.6.4**：下拉刷新指示器、钻入式隐藏用兜底选择器、列表分区调整。
- **v0.6.5**：**日记域引入**（第四个领域文件 `diary.json`、`DiaryView.svelte` + `diary/`）。
- **v0.6.6**：日记拆文件 + 导入导出（Markdown 树 zip）、头部改齿轮、全局搜索混排（任务 + 日记）、markdown 扩展渲染（callout / 公式 / mermaid / markmap / 代码折叠 / front-matter / 链接图标）、输入框加号与编辑器新建模式、CSS 层叠坑（当年踩的那一次）。
- **v0.6.7**：插图随包走、一般卡片下掉角标、手动同步撞 `SYNC_IN_PROGRESS` 不再自己插一轮、窗口几何竞态兜底、搜索态三处修复、桌面链接预览改回标题栏。
- **v0.6.8**：展开态只认存储值、拖动跟手、日记模式的标签子菜单、markdown 扩展渲染落地、编辑器标签/表情删除叉多端统一、CSS 层叠坑修透（`> *` 铁律的来源）。
- **v0.6.9**：标签/表情两段式点按、日记长单行可展开、编辑器 markdown 工具栏（移动端）、返回键拦截器注册表、安卓退出生命周期、桌面编辑器宽高比例、markdown 扩展 v0.6.9 扩充与四个坑、编辑器尺寸比例设置项。
- **v0.6.10**：编辑器工具栏上桌面、同步功能总开关（`features.sync`）、一般卡片的 Markdown 压缩包、首帧缩放不跳变、插图清理（`image_gc.rs`）。
- **v0.6.11**：「已完成」区默认折叠与记忆、特性开关区改灰卡、移动端编辑器元数据行只留图标、分割线细虚线、`skills persist` 默认路径、首帧资料缓存。
