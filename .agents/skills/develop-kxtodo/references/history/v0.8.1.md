# v0.8.1 版本档案（v0.8.0 回归修复 + 一批短需求）

> **这份文件是什么**：v0.8.1 的完整改动档案，分两半——**v0.8.0 引入/被发现的回归**（首屏闪烁、输入框抽风、展开卡顿、视图切换顿挫、工具箱卡住、返回键失灵、同步不回来资料）与**新需求**（周一起始、临期高亮、标签体系重做、可点任务框、列表缩进、存储细分、人民币大写工具…）。
> **什么时候读它**：改首帧渲染 / 外观与资料缓存 / `TaskCard` 展开路径 / 浮层的返回键接管 / 标签与配色 / 日历周起始 / 工具箱之前；排查「点了一下没反应」「冷启动闪一下」「返回键按了没动静」这类症状之前。
> 当前生效的规则以主题文件为准（`frontend.md` / `invariants.md` / `cli.md` / `ledger.md` / `ui-patterns.md`）；这份档案留的是「错的行为长什么样、为什么错」。
> v0.8.0 见 `v0.8.md`，v0.7.x 见另两份。

## 一句话

v0.8.0 的方向没错（渲染去无用功、写路径去放大都留着了），但它把**成本挪到了交互那一刻**，于是长出了五个「点一下顿一下 / 闪一下」的用户可感问题；同时一批「只做了减法的优化」缺了收尾（懒加载没有失败路径、外观缓存只收数字字段、配对时无条件盖设置时间戳）。这一版把欠的收尾补齐，并落了一批短需求。

## 一、v0.8.0 的回归与根因

| # | 症状 | 根因 | 修法 |
|---|---|---|---|
| 1 | 安卓冷启动头像 / 昵称 / 邮箱**闪回默认值** | ① 外观缓存白名单只有 7 个数字字段，`navLayout`（双列）等字符串字段从来没缓存过；② 头像在移动端是直接存进 settings.json 的 dataURL（手机原图几 MB），`localStorage.setItem` 因配额抛错时**整条资料缓存一起写失败**，名字邮箱被头像连累 | 缓存收进整个 `appearance`（读回来过一遍 `normalizeSettings`）；写资料缓存失败时**退一步只写名字邮箱**；移动端头像上传先压到 256px 再存 |
| 2 | 昵称 / 邮箱输入框**越打越多、字符乱跳** | 输入框是受控的，每敲一个字符就 `config.set` 一次 = settings.json 全量写盘 + 快照往返 + `value` 回写，回写打断 IME 组合输入 | 改本地草稿 + **失焦或回车才提交** |
| 3 | 长卡片**首次展开卡顿**（安卓明显） | v0.8.0 把完整渲染从「折叠态白跑」改成「展开时算」，但算的时机落在**展开那一次同步 flush 里**——点下去到画面之间被几百毫秒的 marked+KaTeX+hljs+DOMPurify 占住 | 新增 `lib/deferredMarkdown.ts`：记忆化命中或短文本同步出，其余**双 rAF 之后再算**（单 rAF 仍在当帧绘制前触发，等于没让出时间）；让帧期间画折叠态内容 |
| 4 | 记账 / 日记**点视图切换顿一下** | `setConfig` 是「先 `await coreDispatch` 再本地生效」——一次完整 IPC + settings.json 原子写的往返（安卓几十到上百毫秒）之后 UI 才翻 | 改成**先本地生效、再落盘**，失败按原值回滚。设置是本机权威、没有冲突语义，先生效是安全的 |
| 5 | 桌面点「工具箱」**半天进不去** | 工具子视图的 chunk 加载**没有失败路径**：`await` 一挂就永远停在「正在打开…」 | 列表一露头就预取各工具 chunk；加载失败重试一次再报错；`{#await}` 补 `{:catch}`（5 处懒加载一起补） |
| 6 | **返回键失灵**（本版新引入、被回归用例抓住的） | `createBackGuard` 只按 `active` 翻转注册/注销，而「挂着就等于开着」的浮层（菜单 / 图标选择器 / 日期选择器）从头到尾只用 `true` 调一次，卸载时不会走 `active=false` 那条分支——拦截器永久留在栈里，返回键被一个已经不可见的浮层吃掉 | 新增 `dispose()`，那三类组件在 `onDestroy` 里调 |
| 7 | 清空数据后同步，**头像 / 昵称 / 邮箱不回来，还把别的设备改成默认值** | 配对时有一条「本机已有 settings.json 就把此刻记成设置最新时间」的规则，判据是假的：用户为了配对必然先在设置面板填用户名密码，那一下 `config.set` 就把 settings.json 建出来了 → 任何设备配对都会盖上一个「现在」→ 带着默认资料的本地设置实体赢得 LWW 并推给服务端 | **删掉配对时的自动时间戳**。真正该判断的是「本地有没有用户改过的共享设置」，而 `sync_updated_at` 自己就是答案：只有共享子集的路径会 `bump_sync_updated_at`，没戳 = 从没改过 |
| 8 | 同步过来的资料载荷缺字段时被**静默改回默认** | `apply_settings_record` 把 profile 整块反序列化成 `ProfileSettings`，而它有 serde 默认值（"Example User" / "example@example.com"）——对方没提的键就被理解成「清成默认」 | 改成**逐字段覆盖，缺哪个键就动哪个键** |

## 二、新需求

### 一周从周一开始（`features.weekStart`）
日历视图、日期选择器、周统计、`plannedGroups` 的「本周」**共用 `stores.ts` 的 `weekStart` 派生 store**（`0=周日 / 1=周一`）。网格构建统一走 `diary.ts::leadingBlanks()` 与 `calendarWeekdayHeaders(weekStart)`。**不许各自去读设置**，否则同一个界面里会出现两个「周一」。设置里是「周一 / 周日」二选一的 radio（默认周一）。

### 临期高亮（`features.dueHighlight` + `appearance.dueColors`）
- 三档：`off`（默认）/ `solid`（今天明天后天各取一色）/ `gradient`（按实际剩余时间在三锚点之间插值）。
- 锚点是「今天 0 点 / 明天 0 点 / 后天 0 点」；`gradient` **不叠 5 小时压深**（插值本身就在表达远近，再压一档会在 5 小时那道线上突变）。
- 设了具体时刻且不足 5 小时 → 加重档（底色更实、描边更粗；`solid` 还会把颜色本身压深一档）。
- 只有日期没有时刻的按当天 23:59:59 算（「今天到期」是今天结束前，不是今天 0 点）。已逾期的与已完成的都不画。
- **配色每个页面一套**（`appearance.dueColors[nodeId] = [今天, 明天, 后天]`），默认红 → 橙黄 → 浅黄；在列表三点菜单的「临期高亮色」里改（开关关着时该行隐藏）。
- 纯逻辑在 `lib/dueHighlight.ts`，有单测（分档、插值端点、加重档、自定义色回退）。

### 标签体系重做
- 配色从 5 色扩到**七彩虹 + 灰 + 自定义**（`TagColor` 加 `orange/cyan/purple/custom`，`Tag.hex` 只在 `custom` 时有意义；`custom` 缺 hex 一律退回灰）。两端同一个校验口径：前端 `defaults.ts::normalizeTagHex` / Rust `model::tag_hex`。
- 配色选择器 `TagColorPicker.svelte`：**两排胶囊，5 + 4 各自左右填满**（flex 均分），最后一格是盖在胶囊上的 `<input type="color">` 色盘。
- 右键菜单的标签面板改成三块（`TagMenuPanel.svelte`）：**预置标签**（点一下加到条目上、右侧叉删这条预置、右下角加号把输入框内容存成预置）→ **输入框 + 「存入预置」勾选**（默认勾）→ **两排配色**。删掉了「清除所有标签」按钮（卡片上点标签就能删单个）。
- 预置标签住在 `appearance.tagPresets`（跟着设置同步，上限 64 条，core 侧 `expect_tag_presets` 校验）。

### 其余
- **渲染出来的任务框可点**：`markdown.ts` 的 `checkbox` 渲染器加 `md-task-box` 类并**去掉 `disabled`**（disabled 的表单控件不派发 click）；`lib/markdownTasks.ts` 负责「第 N 个框 ↔ 源码第几行」的对应（判据照抄 marked 的 `listIsTask`，围栏代码块整段跳过），点一下改 `- [ ]` / `- [x]` 再存回去。勾上的行靠 `li:has(input:checked)` 加删除线（`text-decoration` 不会画到原子行内级的 `<input>` 上，所以不必包 span）。
- **编辑器列表缩进**：Tab / Shift-Tab 走 `codemirrorSetup.ts::indentListItem`——整行缩进两格、无序标记按层级轮换 `-` `*` `+`、整块有序列表**同级重新编号**；不在列表里时落回 CodeMirror 的 `indentWithTab`（同一 keymap 里返回 false 即继续往后找）。
- **超链接渲染样式改三档单选**：`features.linkRender` = `off|title|card`（默认 card）。早先两个独立勾选框的四种组合里有两组等价（都勾 = 只有卡片生效），语义不可预期。顺手把复制按钮的图标换成通行的「两个叠放方框」。
- **存储占用细分**：`storage.usage` 新增 `domainFiles` / `historyDir` / `runtimeDir` / `serverDir` / `serverWalBytes`；「其他」桶 = 总数 − 各分项，**由 Rust 一侧算**（两边各算各的必然对不上，也就必然跳变）。设置页对应加了分项与「分项合计」自查行。
- **服务器 WAL 检查点**：SQLite 的自动检查点**不缩小 WAL 文件**，内置主机常年只增不减 → 每 10 分钟一次 `wal_checkpoint(TRUNCATE)`（`Db::checkpoint`）。这个后台任务**必须能被停机叫醒**（用 watch 通道），否则它会一直握着 SQLite 连接，Windows 上主机库目录删不掉（回归用例直接红）。
- **服务器日志单文件上限 8MB**：保留策略只管文件数（最近 7 天）不管单文件多大，一个卡在错误重试里的客户端一天能堆出几百 MB；到顶只停写文件，stdout 照旧。
- **工具箱**：桌面两列卡片（`grid-template-columns: repeat(2, minmax(0,1fr))`）、内容铺满宽度、工具内部左右对齐；工具的按钮行贴右下角（`.toolbox-sub-actions` + `margin-top:auto`）；新增「人民币大写」工具（`lib/rmb.ts`，复用 `parseYuanToCents` 解析，按**四位一节**分级，有单测）。
- **任务日期展示**：卡片上从「M月D日」改成「M月D日 周X」，设了时刻再带 ` HH:MM`。
- **日期选择器的时刻开关**：`withTime` 那一行左侧加勾选框，未勾时右侧时刻按钮置灰不可点；勾上默认取「此刻」，关掉清空时刻值。

## 四、明确决定不做的

- **虚拟滚动 / 实体级增量快照**：维持 v0.8.0 的决策（数据量级不够、风险高于收益）。
- **墓碑剪枝、`selected_node_id` 归位**：同上（复活风险 / 收益低）。
- **`#region` 式把 flags 抽公共结构、`CommandMeta` 单表**：见上表 6/7。
- **把懒加载改回静态导入**：首屏体积的收益是真的；这一版补的是**失败路径与预取**，不是回退懒加载。
- **`Avatar` 改成 dataURL 统一两端**：头像文件与背景图本来就走独立的 blob 同步通道，改名会白折腾；闪的根因在缓存配额，已从压缩那一侧解决。

## 六、新增/变化的铁律（索引）

- **「挂着就等于开着」的浮层必须在 `onDestroy` 里 `backGuard.dispose()`**（否则返回键永久被吃掉）——`invariants.md`「平台与窗口」、`frontend.md`。
- **首帧可见的东西必须进外观/资料缓存**；缓存写入失败要退一步保住能保的——`invariants.md`「前端 Svelte 与渲染」。
- **页面响应优先于资源节省**：`setConfig` 先本地生效再落盘；展开态重活让一帧；懒加载要有预取与失败路径——`frontend.md`。
- **图片入库三档闸门**（插图 5MB / 背景 2MB + 超 10MB 拒收 / 头像务必收到 256px）——`invariants.md`「图片」。
- **`skills validate` 的域名单从 clap 派生**、**help 示例进回归测试**——`cli.md`。
- **跨语言同口径的常量要有测试钉住**（本版新增 `BACKGROUND_MAX_EDGE` 前后端同值）——`invariants.md`。
