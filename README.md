# KXToDo

一个**本地优先**的个人记录中枢：把「要做的事」「发生的事」「花掉的钱」放在同一个应用里。
Windows / Linux / Android 三端同一份数据，可离线使用，也可在多设备间端到端加密同步。

不需要注册账号就能用——数据全在你自己的设备上。

---

## 能做什么

### ✅ 待办

- 分类 → 条目 → 任务三级组织，左侧树可拖拽排序、自选图标
- 任务是 Markdown 卡片：支持代码块、表格、公式、流程图、待办清单、告示块（callout）
- 截止日期与时刻、标签、表情；「我的一天 / 计划内 / 收藏」三个内置视图
- 计划内视图自动分成 已逾期 / 今天 / 近三天 / 本周剩余 / 稍后
- 两种卡片样式：待办卡片（可勾选完成）与一般卡片（纯记录，不算完成度）
- 一般卡片可整条导出成 Markdown 压缩包（含插图），也能从压缩包或文件夹导回

### 📔 日记

- 按**归属日期**归档，一天可以写多篇；补记昨天的事就选昨天的日期
- 三种视图：列表 / 月历（格子上标心情）/ 年→月分组
- 心情、天气、彩色标签；正文同样是 Markdown，可插图片
- 导出成给人看的 Markdown 树（`年/月/YYYYMMDD_标题.md`，元数据在 front-matter 里，插图随包走），也能导回
- 副标题随时告诉你：共几篇、本月几篇、连续写了几天

### 💰 记账

- 记一笔支出 / 收入，或账户间转账（转账不计入收支统计）
- 两级分类（大类 → 子分类），支出与收入各一套，分类与账户都能自选图标和颜色
- 资金账户类型可自定义（现金、银行卡、信用卡、微信、公积金、借入借出…）；信用卡负余额自动计入负债
- 余额永远由「期初 + 流水」推导，改历史账目不用回头修余额；也可以直接设「当前金额」让应用反推期初
- 列表按天成卡、日历看每天收支、统计看趋势与分类占比（可点大类钻取到子分类再到每一笔）、资产看净资产与总资产趋势
- 每笔可附多张票据图片
- 导出 / 导入 Excel（一个 zip 里四张表：说明 / 账户 / 分类 / 账目），搬家或备份都走这条路

### 🔎 其它

- **全局搜索**：任务、日记、记账混排在一起按最近改动排序；记账还能按分类、备注、金额搜（`12.34` / `1,234.56` / `-12.34` 都认）
- **定时任务**（桌面端）：按时间点 / 间隔 / 日历 / 条件触发，跑脚本、启动程序或弹通知，带执行历史
- **桌面通知**与系统托盘，可设全局快捷键唤出/隐藏窗口
- **外观**：主题色、背景色盘 / 莫奈预设 / 自定义图片 + 透明度；六档字号、界面缩放、固定导航的显示项与排布（单列 / 双列 / 只图标）
- **工具箱**：随机数等小工具，两端都有
- **存储空间**：随时查看数据占用构成，一键清理没有引用的插图与旧日志
- **应用内更新**：设置页检查新版，直接下载替换重启

### 🔗 多设备同步（可选）

三种通信方式，任选其一，都是**端到端加密**——服务器只存密文，拿到数据库也读不出内容：

| 方式 | 适合 |
|---|---|
| 局域网 | 同一 Wi-Fi 下的几台设备，其中一台当主机，按名字自动发现 |
| 自建服务器 | 有一台常开的机器，跑 `kxtodo-server` 即可 |
| P2P | 没有公网 IP、不在同一网络，靠打洞直连，零配置 |

加密密钥由你的**用户名 + 密码**派生，密码丢失 = 数据不可恢复。同步范围可以按数据 / 设置 / 任务 / 日记 / 账本分别勾选，随时暂停。

## 下载

从 [Releases](../../releases) 取对应平台的文件（都是固定名，覆盖安装即可）：

| 平台 | 文件 |
|---|---|
| Windows | `KXToDo.exe`（主程序）、`kxtodo-cli.exe`（命令行）、`kxtodo-server.exe`（同步服务器，可选） |
| Linux | `KXToDo.AppImage`、`kxtodo-cli`、`kxtodo-server`（可选） |
| Android | `KXToDo.apk`（arm64 与 armv7） |

Linux 跑 AppImage 需要 FUSE；没有 FUSE 的环境用 `./KXToDo.AppImage --appimage-extract-and-run`。
想用命令行或定时任务的通知功能，把 `kxtodo-cli` 和主程序放在同一目录即可。

## 数据放在哪

| 平台 | 位置 |
|---|---|
| Windows | `%LOCALAPPDATA%\kxtodo\todo-note-data\` |
| Linux | `$XDG_DATA_HOME/kxtodo/todo-note-data/`（通常是 `~/.local/share/…`） |
| Android | 应用私有目录（导出/分享走系统面板） |

里面是五个 JSON 文件（数据 / 设置 / 定时任务 / 日记 / 记账）加插图目录，可以直接复制备份。
应用会在 `backups/` 里保留最近 5 份全量备份。

## 命令行

`kxtodo-cli` 与图形界面共用同一份数据，可以让脚本或 AI 助手替你记录与查询：

```bash
kxtodo-cli task tree                                        # 看看有哪些分类与条目
kxtodo-cli diary add --markdown "今天把同步分层重构完了" --mood 🙂
kxtodo-cli ledger add --amount 30 --account 微信 --category 午餐 --yes
kxtodo-cli ledger stats --month 2026-09                     # 这个月花了多少、钱花在哪
kxtodo-cli --help                                           # 全部命令
```
